# 像素矿工 — 挖矿挂机微信小游戏

## 项目概述

像素矿工是一款基于 Canvas 2D 的微信小游戏，采用放置挂机玩法。玩家控制矿工自动挖矿，通过升级镐子、速度、收益加成等属性，逐步解锁更深层的矿层，获取更丰厚的奖励。

## 操作说明

### 主界面

- **顶部 HUD**：显示当前金币（💰）、钻石（💎）、攻击力（ATK）和单次挖矿收益（GOLD+）
- **矿层栏**：显示当前所在矿层名称、倍率和出产的矿石类型
- **矿工区域**：矿工自动挥镐挖矿，矿石进度条满后破碎并掉落奖励
- **底部按钮区**：6 个功能按钮

### 按钮功能

| 按钮 | 功能 |
|------|------|
| ⛏ 镐子 Lv.x | 升级镐子等级，提高每次挥镐的攻击力 |
| ⚡ 速度 Lv.x | 提高挥镐频率，挖矿更快 |
| 💰 收益+x% | 提高每次挖矿获得的金币倍率 |
| ⏱ 离线xh | 提高离线收益的最大储存时长 |
| 🗺 矿层x/8 | 打开矿层选择界面，切换/解锁矿层 |
| 🏪 商城 | 打开皮肤商城，购买角色和镐子皮肤 |

### 离线收益

关闭游戏后，离线期间矿工会继续以 50% 效率挖矿。再次打开游戏时弹出离线收益窗口，点击领取后播放入场动画（矿工从天而降），然后继续自动挖矿。

离线收益上限可通过升级「离线」按钮提升。

### 萤火虫

挖矿区域偶尔会出现发光的萤火虫，点击可获得持续 20 秒的随机增益 Buff（攻击力或速度翻倍）。

### 矿层系统

9 个矿层从浅到深逐步解锁，需要足够的金币才能解锁下一层。越深的矿层产出越高，但矿石生命值也更高，需要更高的镐子等级才能高效开采。

|------|------|-----------|-----------|
| 0 | 地表层 | Lv1 | 30 |
| 1 | 青石浅层 | Lv24 | 168 |
| 2 | 灰铁岩层 | Lv48 | 312 |
| 3 | 月光晶层 | Lv72 | 456 |

| 7 | 虚空深岩层 | Lv168 | 1032 |
| 8 | 地心终极层 | Lv192 | 1176 |

使用对应推荐等级的镐子，每层均需 12 次挥镐挖掉一个矿石。

## 设计文档

### 技术架构

**平台**：微信小游戏（Canvas 2D）
**基础库**：3.0.0+
**无外部依赖**，纯 JavaScript 手写渲染

### 项目结构

```
minigame-1/
├── game.js              # 游戏入口：渲染循环、触摸处理、动画
├── state.js             # 游戏状态（持久+UI）、逻辑函数
├── data.js              # 静态数据（矿层、皮肤、颜色表、常量）
├── particles.js         # 粒子系统（带对象池）
├── audio.js             # 音频系统（Web Audio API 合成音效）
├── canvas.js            # Canvas 初始化（DPR 缩放）
├── game.json            # 微信小游戏配置
├── project.config.json  # 项目配置
└── README.md            # 本文档
```

### 模块职责

#### canvas.js
创建全屏 Canvas，设置 DPR 缩放，导出 `{canvas, ctx, W, H, dpr}`。

#### data.js
集中管理所有游戏常量：
- `LAYERS[9]`：9 个矿层的完整定义（名称、颜色、生命值、收益、解锁条件等）
- `CHAR_SKINS[6]` / `PICK_SKINS[6]`：皮肤数据
- `CHAR_COLORS[6]` / `PICK_COLORS[6]`：绘制颜色表
- `GROUND_COLORS[9]`、`DUST_COLORS[9]`、`VEIN_RGB[9]`：渲染缓存
- `BUFFS[6]`：萤火虫 Buff 池

#### state.js
分离持久状态（`state`）和 UI 瞬态（`ui`）：
- `state`：gold、ore、pickLv、layer、skins 等 — 存储到 wx.setStorageSync
- `ui`：particles、prog、swing、showLayers、firefly 等 — 不持久化
- 提供所有数值计算函数（pickPower、swingSpeed、cost 计算等）

#### particles.js
粒子系统使用对象池（最大 300 个），减少 GC 压力。
- `spawnP()` / `spawnCoin()` / `spawnRockBreak()`：不同粒子类型
- `updParticles(dt)`：物理更新（重力、衰减）+ 回收

#### audio.js
使用 Web Audio API 程序化合成音效，无需音频文件：
- `playHit()`：挥镐音效（方波 1200→600Hz，60ms）
- `playBreak()`：碎石音效（锯齿波 200→60Hz + 三角波叠加）

#### game.js
主循环 `requestAnimationFrame`：
- `update(dt)`：物理更新、自动挥镐、粒子更新、萤火虫、Buff 计时、自动保存
- `render()`：绘制背景、HUD、矿层栏、矿区、按钮、弹窗、动画
- `touch(x,y)`：触摸事件分发
- 离线入场动画：矿工从天而降（三段动画：下降→准备→回收绳索）

### 核心数值公式

#### 攻击力 (pickPower)
```
base = 2.5
growth = 0.5  # 每级增加
damage = (base + (pickLv - 1) * growth) × (1 + skinBonus('atk')) × buffAtk
```

#### 挥镐速度 (swingSpeed)
```
base = 0.4 swings/sec       (Lv1)
growth = 0.1 per level
speed = (base + (swingSpd-1) * growth) × (1 + skinBonus('spd')) × buffSpd
```

#### 升级花费

| 项目 | 公式 | Lv1 价格 |
|------|------|---------|
| 镐子 | 10 × 1.5^(pickLv-1) | 10 |
| 速度 | 20 × 1.5^(swingSpd-1) | 20 |
| 收益 | 30 × 1.5^(bonusLv) | 30 |
| 离线 | 动态计算 (30分钟收益) | 动态 |

#### 矿石生命值 (rockHP)
各层 HP 按推荐镐等级设计，使得对应等级下恰好 12 刀挖掉一个矿：
```
HP = (2.5 + (targetLv-1) × 0.5) × 12
```

#### 离线收益
```
offlineSec = min(实际离线秒数, 离线升级上限)
效率 = 50% (OFF_EFF = 0.5)
swings = offlineSec × swingSpeed × 0.5
rocks = swings × pickPower / rockHP
gold = rocks × rockGold
ore = rocks × 0.6 × rockOre
```

### 渲染管线

```
render()
  ├─ drawBg()          # 渐变背景、岩层纹理、钟乳石、矿脉、支撑柱、地面、滴水、火焰光效、层特效、浮尘
  ├─ drawHdr()         # 半透明顶部 HUD
  ├─ drawLayer()       # 当前矿层名称栏
  ├─ drawMine()        # 矿石、地面纹理、矿工、稿子、进度条、粒子特效
  ├─ drawBtns()        # 6 个功能按钮
  ├─ drawPopup()       # 离线收益弹窗（动画期间隐藏）
  ├─ drawOfflineAnim() # 入场动画（矿工从天而降）
  ├─ drawLayerPopup()  # 矿层选择弹窗
  ├─ drawShop()        # 商城弹窗
  ├─ drawFirefly()     # 萤火虫特效
  └─ drawToasts()      # 提示消息
```

### 像素风 UI 规范

- **字体**：`"PingFang SC", "Microsoft YaHei", sans-serif`，全粗体
- **按钮**：3D 像素边框（左上亮色高光 + 右下暗色阴影），圆角 6px
- **配色**：深色主题，金色代表金币，青色代表钻石，矿脉色随层变化
